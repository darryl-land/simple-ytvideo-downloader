A very very simple PyQt6 video downloader app that uses yt-dlp.
![Screenshot](https://github.com/darryl-land/simple-ytvideo-downloader/blob/4b0a7ac40a35bade070a92db17f16e294d6986bb/screenshotthing.png)
## Features
* Uses PyQt6
* Downloads video using `yt-dlp`
* Live console ouput of `yt-dlp` downloading video
* Options to enable embedding auto-generated english captions
* Installs `yt-dlp` if it is not installed
